# 2026-09-28

## RS485 换新芯片 — PA8(DE)/PA11(RE) 方向控制

需求：新 485 收发芯片的 DE/RE 由两个独立 IO 控制。发送时 PA8 拉高、发送结束拉低；
接收时 PA11 拉高；不发送时 PA8 低 + PA11 高（收模式为空闲态）。

改动：
- `Core/Inc/rs485.h`
  - 新增方向控制宏 `RS485_DE_ENABLE/DISABLE`、`RS485_RE_ENABLE/DISABLE`；
  - 新增原型 `rs485_enter_tx()`、`rs485_enter_rx()`、`rs485_transmit(data,len,timeout)`；
  - 注释修正：RS485 实际挂在 USART1（原来写成 USART2，是旧注释）。
- `Core/Src/rs485.c`
  - `rs485_transmit()` 统一封装：enter_tx → `HAL_UART_Transmit` → enter_rx；
  - `rs485_enter_tx()`：等 TC → `rs485_rx_harvest()` 取走已收字节 → 停 DMA →
    PA11=0（关接收器，避免自发自收）→ PA8=1 → 总线稳定延时 ~1µs；
  - `rs485_enter_rx()`：等 TC（最后一个停止位真的出线）→ PA8=0 → PA11=1 →
    重启 DMA 接收；
  - `rs485_rx_harvest()` 新增：切 TX 前把 DMA 已捕获字节搬进环形缓冲，防止
    主机命令帧尾被丢；`rs485_rx_pause()` 新增；`rs485_rx_idle_cb()` 加
    `g_rs485_rx_running` 守卫，发送窗口内 IDLE 中断只清标志不重启 DMA；
  - `rs485_init()` 空闲态设为 DE 低 + RE 高；`rs485_tx()` 改为走 `rs485_transmit()`。
- `Core/Src/main.c`
  - `uart_debug()`、`send_string()` 改为走 `rs485_transmit()`（调试串口与 485 是同一个
    USART1，不这样就发不出去）；
  - 删掉开机常拉高 DE 的 `HAL_GPIO_WritePin(GPIOA, RS485_DE_Pin, SET)`；
  - `rs485_init(&huart1, rs485_cmd_dispatch)` 提前到 `CUSTOM_USART1_Init()` 之后、
    第一条 uart_debug 之前。

编译验证通过（无警告）：FLASH 44112 B / 128 KB，RAM 7744 B / 20 KB。
产物：`build/Debug/Y75_Model.hex`、`build/Debug/Y75_Model.bin`。
